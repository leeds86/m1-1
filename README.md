# 경제를 읽는 첫걸음

금리·환율·KOSPI·금·물가·실업률의 2016~2025년 월별 움직임을 초보 투자자의 눈높이에서 살펴본 프로젝트입니다.

## 최종 결과물

1. **분석 리포트:** [REPORT.md](REPORT.md)
2. **시각화:** [images](images) 폴더의 그래프 13개와 REPORT의 설명
3. **Python 코드:** [analysis.py](analysis.py)
4. **GitHub 저장소:** 코드, 데이터, 리포트와 실행 방법을 함께 보관

보너스 과제로 웹 대시보드도 만들었습니다: https://m1-1-eta.vercel.app/

## 가장 먼저 볼 파일

- 분석 내용과 결론을 읽으려면 `REPORT.md`
- 계산 과정을 확인하거나 다시 실행하려면 `analysis.py`
- 원본으로 사용한 월별 값을 확인하려면 `data/economic_indicators_monthly.csv`
- 대시보드 파일을 확인하려면 `web/`

## 폴더 구조

```text
m1-1/
├── README.md                         # 프로젝트와 실행 방법
├── REPORT.md                         # 최종 분석 리포트
├── analysis.py                       # 전체 분석 코드
├── requirements.txt                  # 필요한 Python 라이브러리
├── data/
│   └── economic_indicators_monthly.csv
├── images/                            # 리포트 그래프 13개
└── web/                               # 보너스 웹 대시보드
```

## 분석을 다시 실행하는 방법

Python 3.10 이상이 필요합니다. 프로젝트 폴더에서 아래 명령을 순서대로 실행합니다.

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe analysis.py
```

`analysis.py`는 다음 작업을 순서대로 수행합니다.

1. 월별 데이터 121개(변화 계산용 2015-12 포함)를 읽습니다.
2. 빠진 달·중복 날짜·잘못된 값을 확인합니다.
3. 가격 변화율과 금리·물가·실업률의 차이를 계산합니다.
4. 상관관계, 금리 변화 구간, 사건 전후, 환율 분해와 예측을 계산합니다.
5. `images/`의 그래프 13개와 `web/data/`의 대시보드 자료를 만듭니다.

웹 화면을 로컬에서 보려면 다음 명령을 실행하고 http://127.0.0.1:8765 를 엽니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

웹 화면만 실행할 때는 Python 외의 분석 라이브러리가 필요하지 않습니다. `web/index.html`을 직접 열면 브라우저 보안 제한으로 데이터와 지표 목록을 불러오지 못할 수 있으므로 위 서버 주소로 접속합니다. 서버를 실행한 터미널은 화면을 사용하는 동안 열어 둡니다.

## 데이터 출처

분석 기간은 2016-01~2025-12이며, 첫 달의 변화를 계산하기 위해 2015-12 값도 포함했습니다.

| 지표 | 출처와 항목 | 사용 기준 |
|---|---|---|
| 기준금리 | 한국은행 ECOS `722Y001 / 0101000` | 월말 값 |
| 원/달러 환율 | 한국은행 ECOS `731Y004 / 0000001 / 0000100` | 월평균 |
| KOSPI | 한국은행 ECOS `901Y014 / 1070000` | 월말 종가 |
| 소비자물가지수 | 한국은행 ECOS `901Y009 / 0` | 전년 같은 달 대비 상승률로 계산 |
| 실업률 | 한국은행 ECOS `901Y027 / I61BC / I28B` | 계절조정 월별 값 |
| 금 가격 | World Bank Pink Sheet, Gold | 달러/트로이온스 월평균 |

- 한국은행 ECOS: https://ecos.bok.or.kr/
- World Bank Commodity Markets: https://www.worldbank.org/en/research/commodity-markets

공개 데이터는 2026-09-17에 수집했습니다. 금 가격은 2025-06부터 산정 기준이 바뀌었습니다. 현재 저장소에는 분석에 사용한 정리된 CSV를 포함했으며 API 인증키와 수집 원본은 포함하지 않았습니다.

위 수집일은 기존 저장소에 기재된 기록입니다. 당시 원본과 수집 스크립트가 없어 수집 이력 자체를 독립적으로 확인하지는 못했습니다. 현재 `analysis.py`는 CSV부터 분석을 재현하며, 제공기관에서 자료를 내려받거나 CPI 원지수에서 전년비를 다시 계산하는 코드는 포함하지 않습니다.

### 자료 조회와 변환

다음은 위에 기록된 항목으로 자료를 다시 찾는 절차입니다. 당시 수집 과정을 복원했다는 기록은 아닙니다. 현재 조회 자료는 개정 때문에 저장된 값과 다를 수 있으므로 항목·단위·집계 기준·조회일과 차이를 먼저 확인합니다.

1. [ECOS](https://ecos.bok.or.kr/)에서 위 통계표·항목을 검색하거나 [공식 Open API 안내](https://ecos.bok.or.kr/api/)를 이용합니다. API 인증키는 저장소에 올리지 않습니다. 가격·금리·실업률은 2015-12~2025-12를 준비하고, 월말·월평균·계절조정 기준을 구분합니다.
2. CPI 원지수로 2015-12부터의 전년비를 계산하려면 2014-12~2025-12가 필요합니다. 계산식은 `(이번 달 CPI / 전년 같은 달 CPI - 1) × 100`입니다. 기준연도 변경이나 개정 여부도 확인합니다.
3. [World Bank Commodity Markets](https://www.worldbank.org/en/research/commodity-markets)의 Pink Sheet 중 **Monthly prices**에서 `Gold` 열과 달러/트로이온스 단위를 확인해 2015-12~2025-12를 선택합니다. 연간값·예측값과 구분하고 해당 자료판의 산정 기준 주석과 이용 조건을 함께 확인합니다.
4. 날짜를 `YYYY-MM`로 통일하고, 아래 열 순서로 121행을 맞춥니다. `inflation_yoy`는 CPI 원지수가 아니라 계산한 전년비입니다.

```text
date,base_rate,usdkrw,kospi,unemployment,inflation_yoy,gold_usd
```

월간 가격 변화율은 `(이번 달 가격 / 지난달 가격 - 1) × 100`, 금리·물가 전년비·실업률의 변화는 `이번 달 비율 - 지난달 비율`(%p)입니다. 입력 CSV의 첫 달은 다음 달의 변화 계산에 사용하며, 실제 분석은 2016-01~2025-12의 120행입니다. 웹 CSV는 분석 대상 120행×6지표를 세로형 720행으로 바꾼 것입니다.

누락·중복·빈 값·비유한값·열 이름이 다르면 분석을 중단하고 자동 보간하지 않습니다. 극단값은 큰 수치라는 이유만으로 제거하지 않되, 오류 여부는 해당 월과 전월의 제공기관 원자료를 함께 대조해야 합니다. 현재 원자료 전수 대조 기록은 없으며, 저장된 CSV를 기준으로 계산과 결과의 일관성을 확인했습니다.

## 분석할 때 주의한 점

- 가격 지표는 월간 변화율(%), 금리·물가·실업률은 전월과의 차이(%p)를 비교했습니다.
- 상관관계는 두 지표가 함께 움직인 정도이며 원인과 결과를 증명하지 않습니다.
- KOSPI는 배당을 포함하지 않고, 금·환율은 월평균이라 실제 투자 수익률과 다를 수 있습니다.
- 사건 전후 분석은 다른 사건과 정책의 영향을 분리하지 못합니다.
- 환율 예측은 방법을 학습하기 위한 과거 실험이며 현재 전망이 아닙니다.

## 보너스 과제

- `web/`에 기간·지표·금리 변화 조건을 바꿀 수 있는 대시보드를 만들었습니다.
- 공개 URL: https://m1-1-eta.vercel.app/
- 환율을 장기 흐름·계절 움직임·나머지 움직임으로 나누는 STL 분해를 수행했습니다.
- 마지막 값 유지와 단순 지수평활 방법으로 1·3·6개월 뒤 환율을 과거 자료에서 시험했습니다.
- CSV 다운로드는 선택 기간과 금리 조건에 해당하는 **6개 지표의 원본 값**입니다. 화면의 단일 지표 선택·전월 대비 표시와는 구분합니다.
