# 데이터 출처 검증 기록

검증일: 2026-09-17. 공식 자료 수집과 월별 통합을 실행했다. 분석·대시보드·배포는 아직 완료하지 않았다.

## 한국은행 ECOS

공식 서비스: https://ecos.bok.or.kr/api/

공식 API를 직접 호출해 확인한 항목:

| 용도 | 통계표 코드 | 항목 코드 | 확인 상태 |
| --- | --- | --- | --- |
| 기준금리 | 722Y001 | 미확정 | 통계표명 '한국은행 기준금리 및 여수신금리', 일별 주기 확인 |
| 원/미국달러 | 731Y001 | 0000001 | 매매기준율, 일별, 원 단위, 1964년부터 제공 |
| KOSPI | 802Y001 | 0001000 | 일별, 1980.01.04=100, 1995년부터 제공 |

월별 자료 코드는 아직 확정하지 않았다. 일별 환율의 월평균과 KOSPI의 마지막 관측일 값을 계산하는 경로를 사용할 수 있다. 기준금리 세부 항목, 물가, 계절조정 실업률은 인증키 설정 후 공식 메타데이터로 검증한다.

sample 키로 120건 요청 시 ERROR-301과 'sample은 최대 10건 이내에서 호출이 가능합니다' 응답을 확인했다. 전체 수집에는 개인 인증키를 사용한다. 샘플 한도를 피하려는 반복 수집은 하지 않는다.

### 로컬 인증키 설정

1. 공식 ECOS Open API 페이지에서 인증키 신청 안내에 따라 키를 발급받는다.
2. 프로젝트 루트의 `.env.example`을 `.env`라는 이름으로 복사한다.
3. `.env`의 빈 값에 키를 입력한다: `ECOS_API_KEY=발급받은값`
4. 키는 채팅·스크린샷·GitHub에 포함하지 않는다. `.gitignore`에서 `.env`는 제외된다.

## 인증 후 실제 수집 결과

| 지표 | 공식 통계표/항목 | 수집 건수 |
| --- | --- | --- |
| 기준금리 | 722Y001 / 0101000 / M | 121 |
| 월평균 원/달러 | 731Y004 / 0000001 / 0000100 / M | 121 |
| KOSPI 종가 | 901Y014 / 1070000 / M | 121 |
| 소비자물가 총지수 | 901Y009 / 0 / M | 133 |
| 계절조정 실업률 | 901Y027 / I61BC / I28B / M | 121 |

개인 키 인증 성공. 원본 JSON과 세계은행 XLSX는 data/raw에 저장했다. manifest.json은 출처·수집시각·SHA256을 기록하며 키를 포함하지 않는다.

소비자물가는 2014-12부터 받아 전년 동월 대비 상승률을 계산했다. 비교를 위한 2015-12 선행 관측을 포함하고 본 분석 구간은 2016-01~2025-12로 제한했다. 월별 통합 결과 120개월×6지표=720행, 누락 값 0개를 확인했다. 중복·누락·비숫자 거부 및 변화율/퍼센트포인트 계산 테스트 4개가 통과했다.

### 금 가격 정의 변경

World Bank Monthly Prices의 Gold 열 단위는 USD/troy oz이다. Description 시트는 2025-06부터 spot average of daily rates, 그 이전은 런던 오후 고시가격(순도 99.5%)의 일별 평균이라고 설명한다. 해당 변경을 통합 CSV의 memo에 표시했다. 발표 시점 기준 데이터 빈티지는 아니므로 당시 이용 가능했던 자료를 완벽히 재현하는 분석이라고 주장하지 않는다.

위 표가 앞부분의 예비 후보 목록보다 우선한다.

### 기준금리 독립 대조 (2026-09-18)

ECOS 722Y001 / 0101000 / D에서 2015~2025년 일별 4,017건을 조회해 월별 마지막 관측값으로 집계했다. 사용 중인 2015-12~2025-12 월별 121개 값과 대조한 결과 누락 0건, 불일치 0건이었다. API URL과 인증키는 검증 로그에 출력하지 않았다.

### 공개 이용 조건 확인 상태 (2026-09-18)

[세계은행 해당 데이터셋](https://datacatalog.worldbank.org/search/dataset/0038238/commodity-prices-history-and-projections)은 Public 및 Creative Commons Attribution 4.0을 명시한다. [데이터 이용 조건](https://datacatalog.worldbank.org/public-licenses)에 따라 World Bank, 데이터셋명, 라이선스와 가공 내용을 밝히고 제공기관의 보증으로 오인시키지 않는다. 원본 XLSX 전체가 아니라 필요한 금 시계열과 계산 결과를 사용한다.

[ECOS](https://ecos.bok.or.kr/#/) 하단의 통계정보이용지침을 브라우저로 직접 열람했다. 한국은행 작성 자료는 출처를 표시해 사용·가공·재배포할 수 있고, 타 기관 작성 자료는 출처를 명시한 비상업적 이용이 가능하다고 안내한다. 타 기관 자료의 상업적 이용에는 해당 기관의 승인이 필요하다. [Open API 이용약관](https://ecos.bok.or.kr/api/#/) 제7조는 이 지침 준수 및 ECOS 제공 정보임을 표시하도록 규정한다.

따라서 현재 범위는 **무료·비상업적 교육용 프로젝트**로 한정한다. 광고·구독·유료 데이터 판매 등으로 전환할 때에는 ECOS 외부기관 자료의 조건과 승인을 다시 확인해야 한다. 웹 화면에 출처·수집일·가공 내용·비보증 문구를 추가했다. 수집 원본과 인증키는 공개하지 않는다. 이는 확인한 정책을 프로젝트 운영에 반영한 기록이며 모든 용도에 대한 포괄적 이용 허가를 뜻하지 않는다.
