- CSV 실제 저장 확인: 금리 인상 달 선택 시 12개월 × 6지표 = 72행. 다운로드 폴더의 CSV를 읽어 날짜 집합과 모든 수치가 웹 원자료와 일치함을 검증했다. 자동화 download 이벤트의 타임아웃과 실제 저장 성공은 별개였으며 코드 수정은 필요하지 않았다.
- 무료·비상업적 교육용 공개 이용 조건 확인 및 웹 출처 표시 반영. 근거와 상업적 전환 주의는 DATA_SOURCES.md 참조.
- 대시보드 스크린샷 3개 및 기간/필터 변경 시나리오를 [DASHBOARD_DEMO.md](DASHBOARD_DEMO.md)에 기록했다. 서비스화 보너스의 스크린샷 제출 방식에 해당한다.
